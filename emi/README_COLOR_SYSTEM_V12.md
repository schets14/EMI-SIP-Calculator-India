# Visual system v12

The app now uses a restrained professional finance palette.

- Light: soft neutral background, white cards, steel blue primary, slate secondary, muted financial green.
- Dark: space-inspired navy background (`#071426`) with navy raised surfaces, avoiding pure black and neon purple.
- Gradients are limited to hero/primary visual anchors.
- Status colors remain semantic rather than decorative.
- Charts use muted series colors instead of neon fills.

This follows Material 3's surface/color-role approach: surfaces carry hierarchy while primary/secondary colors are used selectively. Dark themes use tonal surface differences rather than making every component brightly colored.
